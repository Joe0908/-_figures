# Phase 2A 变更记录

日期：2026-09-28。范围：最小共享模块与F01。第一阶段冻结文件保留原样；本文件记录它们在本阶段的具体落实和局部调整。

## 人工微调的保存规则

原规则：第一阶段要求正式发布前把全部确认的排版调整并回Python，overrides只作过程记录。

变更依据：新`prompt 2.docx`第10节明确区分科学结构与publication micro-adjustments，允许后者保存在版本控制的Tavotto overrides。这是用户提供的新规则，不是实施者从渲染效果推断的需求。

新规则：科学内容、对象、关系、方向、层级及主要布局必须回到Python；小幅文字位置、间距或视觉平衡可保留为版本控制的覆盖文件，稳定重要的改动优先并回Python。本次未使用Tavotto overrides，当前输出从Python直接重建。

## 从规格到最小实现

原方案：十类母版及通用FigureSpec、RelationSpec、ArtistHandle等接口，供全书后续扩展。

本次需要：F01仅有空间包含、集合、组织、概念放大与链内区域，不需要转录、干预、风险、反馈的API。

实际实现：`book_style.py`、`visual_grammar.py`、`layout_utils.py`、`export_utils.py`加一个F01文件；BuildResult与Box保留在布局模块，不额外制造契约框架。没有提前实现其他图的颜色、箭头或模块。

## 真实渲染发现与修复

| 原始落实 | 实际问题 | 修正与理由 |
| --- | --- | --- |
| 标题中心92 mm、底注7.5 mm | 渲染文字包围盒侵入6 mm安全边距 | 标题降至90.5 mm，底注升至8 mm；维持字号和画布，不缩字 |
| “放大”文字与斜虚线相邻 | 路径检查发现线穿过文字安全区 | 文字上移2 mm，为双引线留下通道 |
| 染色体定义放在曲线下方 | 下一级放大线穿过定义文字 | 定义移到染色体标题下，直接DNA/蛋白标注分置两侧，读者不必猜圆形身份 |
| 核内一条示意曲线靠近边界 | 初版目检发现贴近或跨出核边缘 | 内移并缩短这一条示意曲线，保留少量染色体仅为示意的说明 |
| 下一级放大选区高度14 mm | 目检发现选区没有包住对应曲线的峰部 | 高度增至18 mm，保持无箭头的概念放大含义 |
| 第一阶段未选定字体及SVG部署方式 | 当前机器没有可直接随项目交付的Noto/思源静态中文TTF | 随包提供OFL Noto Sans SC Regular静态字体；PDF嵌入，SVG保留text并嵌入当前用字WOFF子集，不安装系统字体 |

新增中性浅灰`region_fill`，仅用于沿链区域高亮和蛋白示意填充；它不表示新的生物学层级或关系。基因区域同时用位置、边界、局部加粗轨道和括号区分，灰度下也成立。170×100 mm、主要9.5 pt、次要9 pt和说明8.5 pt、四周6 mm的起始规范保留。

## 检查及适用边界

初版几何报告确实检测到3项文字安全边距和2项路径穿字问题；修正后重新渲染三格式并复查。最终验证JSON记录实际物理尺寸、像素、字体嵌入、矢量路径、SVG text、语义ID及源码/输出哈希。`checks/validate_f01.py`包含真实负例，用来证实越界、文字碰撞、小字、ID错误、线穿字和重复ID会被拒绝。
