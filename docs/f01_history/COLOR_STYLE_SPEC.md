# 运行生命统一配色规范

版本 1.0，2026-09-28。采用「海青与铜」，已应用于 F01。此规范为 F02–F30 提供共用颜色角色；后续各图仍需在实际内容和版面中验证。本轮只调整 F01 的颜色，构图、14 条文字、77 个对象、对象关系、线宽、字号和 170×100 mm 尺寸均沿用已交付版本。

## 三套候选

| 语义角色 | A 海青与铜 | B 石蓝与砂金 | C 松绿与绛砂 |
| --- | --- | --- | --- |
| 主结构色：核心科学对象及连续结构 | `#2F6174` | `#425B76` | `#416F67` |
| 次结构色：容器与周边结构 | `#6B8B7A` | `#66877E` | `#6D8095` |
| 强调色：当前解释的局部区域或焦点 | `#A6633F` | `#946D2E` | `#A45D59` |
| 补充色：需要区分的相关辅助对象 | `#827592` | `#907A85` | `#8D865D` |
| 中性色：标题、正文及通用说明 | `#26353E` | `#2D3540` | `#2F3B38` |
| 背景色：白色纸面与画布 | `#FFFFFF` | `#FFFFFF` | `#FFFFFF` |

A 的蓝青主线与铜色重点形成克制的冷暖对照，浅鼠尾草和灰紫用于较轻的辅助层次，适合本书细线、留白和逐层解释的风格。B 更偏经典教材，石蓝稳重、砂金温暖，但生命感较弱。C 的自然气息更强；后续涉及风险、反馈或干预时，需要格外避免读者将绿与红自动理解成好与坏。

**选择 A「海青与铜」**。它能把主要结构、环境、局部焦点和相关蛋白分开，同时避免大面积高饱和颜色。颜色表示图中的解释角色，不表示物质的真实颜色。

## F01 的实际应用

| 对象 | 颜色与派生值 | 用意 |
| --- | --- | --- |
| 细胞边界与底色 | `#6B8B7A`／`#F3F6F4` | 鼠尾草边界和极浅底色标出外层容器 |
| 细胞核边界与底色 | `#618795`／`#EAEFF1` | 蓝青边界与浅蓝底色区分内层位置 |
| 被选中的染色体内 DNA、放大后长 DNA、下方 DNA 主骨架与延续线 | `#2F6174` | 跨尺度保持同一色族，表达同一 DNA 的组织与放大 |
| 其他染色体与全部 DNA 横档 | `#638897` | 降低次级线权重；HBB 内横档也保留 DNA 色族 |
| 相关蛋白边框、标注引线与圆形底色 | `#827592`／`#EBE9EE` | 辅助色只区分已有蛋白对象 |
| HBB 区域边框、已有粗区段、下方括号及“基因 HBB” | `#A6633F` | 将注意力集中在 DNA 内部的一个区域 |
| HBB 区域底色 | `#EFE3DC` | 浅铜色覆盖已有区域，不新增独立物体 |
| 普通文字、基因组集合括号及其引线 | `#26353E` | 保持文字清晰，集合标记不承担新的物质身份 |
| 放大框、放大虚线、“放大”与图下注释 | `#677278` | 通用导航与说明保持中性 |
| 长 DNA 标注引线 | `#2F6174` | 跟随所指 DNA 对象的颜色 |
| 画布 | `#FFFFFF` | 维持书页留白和各格式一致性 |

染色体与 DNA 通过组织形态、原有放大框和尺度位置区分，颜色保持连续。HBB 的两条重点轨道与边框为铜色，其内部横档仍为蓝青色，帮助说明这是同一 DNA 上被选出的区域。F01 原本没有有向箭头，本次仍以原有无箭头虚线表示放大。

## 向 F02–F30 迁移

1. 在每张图编码前，列出核心对象、次级容器、局部焦点和辅助对象，再选择角色。无需用满全部颜色。
2. 同一对象跨面板、跨尺度时保持同一色族。DNA 在关联图中延续蓝青；若具体图确需例外，应记录并直接标注，不能用无说明换色制造新物质身份。
3. 铜色默认表示解释重点，不自动表示疾病、危险、异常、激活或疗效。风险、正负变化、干预等新含义必须有明确图例和冗余形状或线型，不能默默重用颜色语义。
4. 通用标签采用中性深色。局部重点标签可用铜色，但放在浅色区域内的文字优先用中性色。辅助色主要用于图形，不用于细小正文。
5. 后续有向关系线随主要结构使用蓝青或中性深色；补充对象的引线可随对象色。方向、因果、抑制和放大仍由已确定的箭头形状及线型表达，不能只靠换色。
6. 浅底色用于区分原有容器或区域，不为填满色板新增色块。用不透明混色值导出，避免透明叠加使交叠处出现第三种含义。
7. 每张图在实际出版尺寸下检查彩色、灰度、文字对比及三种导出；颜色失效时仍应靠边框、位置、线型和文字读懂。当前没有逐图验证 F02–F30。

## 源码与可调参数

`book_style.py` 的 `PALETTES` 保存三套基色，`PALETTE` 选择当前方案，`ColorTuning` 保存派生色强度。单图文件中的 `apply_f01_colors()` 只设置已有对象的文字色、线色、边框色和填色；构图代码保持原坐标。`build_figure(palette=..., tuning=...)` 可在内存中预览其他配色。

派生色按 sRGB 通道计算：`基色 × weight + 背景色 × (1 − weight)`，再取 8-bit 色值。weight 是混色权重，不是对象透明度。当前参数如下。

| 参数 | 默认值 | 控制对象 | 微调建议 |
| --- | ---: | --- | --- |
| `cell_fill_weight` | 0.08 | 细胞底色 | 0.06–0.10，避免外层填色过重 |
| `nucleus_fill_weight` | 0.10 | 核底色 | 0.08–0.12，保持内外层可辨 |
| `nucleus_edge_weight` | 0.76 | 核边界 | 保持默认；加深时可试 0.80 |
| `secondary_dna_weight` | 0.75 | 其他染色体与 DNA 横档 | 保持默认；纸样偏淡时可试 0.80 |
| `protein_fill_weight` | 0.16 | 蛋白圆形底色 | 0.12–0.20，维持辅助地位 |
| `gene_fill_weight` | 0.18 | HBB 浅底 | 当前已清楚；偏重可降至 0.14–0.16 |
| `muted_weight` | 0.70 | 注释、放大框与放大线 | 不建议减小；8.5 pt 注释需要足够对比 |

例如，在 `ColorTuning` 中把 `gene_fill_weight` 改为 `0.16`，再运行 F01 脚本，便可只减淡 HBB 底色。要长期更换全书方案，修改 `PALETTE = PALETTES["sea_copper"]` 的选择，然后重建并检查。微调区间是试调建议，尚未逐一验证；不要把多项参数同时调至极端。

## 可读性与验证边界

当前方案的 sRGB 亮度对比实算为：普通文字对白底 12.64:1，铜色 HBB 文字对白底 4.69:1，注释对白底 4.94:1；细胞和核边界对各自底色约 3.45:1 与 3.35:1。HBB 铜色边框对浅铜底为 3.73:1，区域内蓝青横档对浅铜底为 3.04:1。这些是设计检查值，不是印刷认证。

蓝青与铜色之间的亮度对比约 1.45:1，因此灰度下辨认 HBB 依靠保留的区域边框、粗轨道、括号及标签。已查看彩色与灰度渲染；三格式保持原生矢量与可编辑文字。配色只增加阅读线索，不替代图形结构。

输出保持 170×100 mm 暂定出版尺寸、600 dpi PNG、矢量 PDF、文字保留的 SVG。现为 sRGB 交付；最终纸张、印刷 ICC、CMYK 转换和打样尚未验证。真人理解、色觉差异读者测试及 Tavotto 实机编辑也尚未验证。
